# Ranklit

Next.js 16 + Tailwind v4 marketing site for Ranklit (local SEO for Google Business Profiles).

- **Before building or changing any page or component, read `DESIGN.md`** (tokens, components, motion, dark-mode rules, accessibility rules, new-page template, ship checklist) and follow it.
- Logo and brand files: `BRAND.md`. `src/components/logo.tsx` is generated by `scripts/brand/kit.py`, so never edit it by hand.
- Light theme is the default; dark is opt-in through the header toggle.
- Keep the previous version of anything you redesign as a switchable backup, and tell the user the one-line revert.
- Ask the user (interactive question) for style, scope or legal-risk decisions instead of guessing.
- Verify with `npx tsc --noEmit`, `npm run lint` and `npm run build`.
